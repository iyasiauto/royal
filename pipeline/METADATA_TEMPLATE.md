# YouTube Metadata Template (new structure, effective 2026-09-20)

Every video folder must contain a metadata TXT following this exact structure.

```
3 Alternative Titles — 20% Improved
<title 1>
<title 2>
<title 3>

Short Description
<2-3 sentence dramatic summary of the story>

<disclaimer paragraph, e.g.:>
The video is based on a narrative reconstruction and reported accounts. The claims presented should not be treated as independently confirmed facts.

Video CHAPTERS:
<MM:SS Chapter title, generated from the video's section headings in order>

Hashtags: 3-4 Related to video
<space-separated hashtags, e.g. #RoyalFamily #BreakingNews #...>

Tags: 4-5 Related to video
<comma-separated tags>

📌 Pinned Comment
<engagement question for the pinned comment>
```

## Thumbnail rule (effective 2026-09-20)
- Every video folder must contain **2 new thumbnails**, built from the current
  video's topic, in **1280x720**, ultra-realistic 4K HD style.
- Follow the 2 approved template types (see THUMBNAIL_TEMPLATES.md once both
  reference images are received; only 1 of 2 received so far on 2026-09-20).
- Saved as `thumbnail_1.jpg` / `thumbnail_2.jpg` (or _1/_2 PNG) inside the
  video's folder next to the final MP4.
